# 古诗格律校勘台

面向诗词编辑与校勘人员的浏览器工作台。可逐字标注平仄、韵组和停顿，建立对仗关系，记录每条判断依据，并对多个异文版本进行并排定位。

## 功能

- 录入诗句并按五言、七言格律模板逐字对照。
- 平仄、停顿、韵组、判断依据和批注可逐字维护。
- 自动提示出律位置、一三五位置可接受变体、待标字和重复用韵。
- 建立句间对仗关系，记录关系说明。
- 多版本独立校勘，字符级并排比较与上下处差异定位。
- 文档级撤销/重做、键盘巡校和浏览器本地持久化。
- 导出包含字音标注、检查记录和版本来源的 Markdown 校对稿。
- 针对平板和桌面优化布局，支持长时编辑。
- 导入韵谱包提供字音候选，经裁决队列确认后写入校勘稿。

## 韵谱包与数据所有权

人工标注与韵谱包分属两套数据所有权，互不越界：

- **包只提供候选**：导入韵谱包不会改动校勘稿。每个位置的包字音以候选形式进入「韵谱裁决」页签的裁决队列，与现稿并排对照，冲突项单独标出。
- **确认才写稿**：校勘员逐项「采用候选 / 保留现稿」，或批量采纳无冲突候选；确认时候选才写入当前校勘稿，并记录来源包与版本。未决冲突一直留在队列中。
- **包更新**：导入新版包后，依附旧包的未确认位置自动退回重核；已确认内容全部保留，仅标出「旧依据」，可在复核区采用新候选或转为人工判定。
- **失败与重试**：导入校验失败时不触碰任何状态，上一包与裁决进度完整保留；同一版本重复导入是幂等空操作，重试不会产生重复记录。
- **旧数据升级**：早期版本的数据打开时，既有判定一律视为人工确认（带迁移标记），不会被任何包候选覆盖。

韵谱包为 JSON 文件：

```json
{
  "id": "pingshui-2026",
  "name": "平水韵字音包",
  "version": "2026.10",
  "entries": {
    "春": { "tone": "平", "rhyme": "上平十一真", "basis": "《平水韵》上平声十一真" }
  }
}
```

`tone` 只接受 `平 / 仄 / 中`，`rhyme`、`basis` 可留空。页面提供两个示例包（v2026.06 与修订版 v2026.10），可直接体验导入、裁决与包更新流程。


## 技术栈

- Angular 19（standalone components）
- TypeScript
- NG-ZORRO
- RxJS 与 Angular Signals
- Less
- 原生 `localStorage`

## 本地开发

```bash
npm install
npm start
```

浏览器打开终端提供的本地地址。

## 测试

```bash
npm test          # Karma + Jasmine（需要本机 Chrome）
npm run test:smoke  # 无浏览器环境下验证韵谱包数据所有权语义
```

## 生产构建

```bash
npm run build
```

生产文件位于 `dist/app/browser/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `↑ / ↓ / ← / →` | 在字格中移动 |
| `1 / 2 / 3` | 标为平 / 仄 / 中 |
| `R` | 循环切换韵组 |
| `A` | 采用当前字的韵谱候选 |
| `Space` | 切换停顿标记 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 本地保存提示 |

## Docker

容器内由 nginx 监听端口 `80`，源码不硬编码宿主端口。

```bash
docker build -t classical-poetry-meter-editor .
docker run --rm -p 10015:80 classical-poetry-meter-editor
```

宿主端口 `10015` 仅用于本地运行示例，实际端口由根编排文件统一管理。
