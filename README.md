# 古诗格律校勘台

面向诗词编辑与校勘人员的浏览器工作台。可逐字标注平仄、韵组和停顿，建立对仗关系，记录每条判断依据，并对多个异文版本进行并排定位。

## 功能

- 录入诗句并按五言、七言格律模板逐字对照。
- 平仄、停顿、韵组、判断依据和批注可逐字维护。
- 自动提示出律位置、一三五位置可接受变体、待标字和重复用韵。
- 建立句间对仗关系，记录关系说明。
- 多版本独立校勘，字符级并排比较与上下处差异定位。
- 人工标注与韵谱包分属两套数据所有权：韵谱包只提供字音候选，校勘员确认（采纳 / 保留人工）后才写入校勘稿，未决冲突留在裁决队列。
- 韵谱包更新后，仅依赖新包的未确认位置退回重核；已确认内容保留，候选已变化者标出“旧依据”待核。
- 韵谱包导入采用完整校验与事务式更新：导入失败保留上一包与裁决进度，同包同版本重复导入幂等忽略。
- 旧版本地数据自动升级：现有判定一律视为人工确认。
- 文档级撤销/重做、键盘巡校和浏览器本地持久化。
- 导出包含字音标注、检查记录和版本来源的 Markdown 校对稿。
- 针对平板和桌面优化布局，支持长时编辑。

## 技术栈

- Angular 19（standalone components）
- TypeScript
- NG-ZORRO
- RxJS 与 Angular Signals
- Less
- 原生 `localStorage`

## 本地开发

```bash
npm install
npm start
```

浏览器打开终端提供的本地地址。

## 生产构建

```bash
npm run build
```

生产文件位于 `dist/app/browser/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `↑ / ↓ / ← / →` | 在字格中移动 |
| `1 / 2 / 3` | 标为平 / 仄 / 中 |
| `R` | 循环切换韵组 |
| `Space` | 切换停顿标记 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 本地保存提示 |

## Docker

容器内由 nginx 监听端口 `80`，源码不硬编码宿主端口。

```bash
docker build -t classical-poetry-meter-editor .
docker run --rm -p 10015:80 classical-poetry-meter-editor
```

宿主端口 `10015` 仅用于本地运行示例，实际端口由根编排文件统一管理。

## 韵谱包格式

韵谱包为 JSON 文件（UTF-8），`entries` 支持数组或以字头为键的对象：

```json
{
  "id": "ping-shui-rhyme",
  "name": "平水韵常用字音",
  "version": "v1",
  "entries": [
    { "char": "春", "tone": "平", "rhyme": "上平十一真", "basis": "《平水韵》上平十一真" }
  ]
}
```

字段校验：`name`、`version` 必填；每条候选必须含 `char`、`tone`（平/仄/中）、`rhyme`、`basis`，字头不可重复。
校验不通过时不会写入任何数据；裁决进度按“版本 × 句位”记录，与包版本绑定。
“韵谱裁决”页提供示例包 v1/v2，可演示冲突裁决、包更新后旧依据保留与重核流程。
